# Azure icons

Microsoft's Azure architecture icons, V23, from the
[Azure Architecture Center](https://learn.microsoft.com/azure/architecture/icons/)
(downloaded 2026-11-06). `scripts/architecture.py` embeds them in
`assets/architecture.svg`, each beside its service's full name. That's how Microsoft's
terms ask for them to be used, and only to stand for the Azure service they were designed
for. The files are byte-for-byte as downloaded: don't edit, crop, recolor or rotate them.
To use an icon the diagram doesn't have yet, copy it from the same download, keeping its
file name, and add it to `ICON_FILES` in the script.
