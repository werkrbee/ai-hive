---
description: Draft GitHub issues for a sprint from ROADMAP.md and a sprint plan file.
---

Read `ROADMAP.md` and the referenced `docs/sprints/<sprint>.md`. For each unchecked item:

1. Propose a GitHub issue — title (imperative, Conventional-Commit-flavored), a short body
   with acceptance criteria, labels, and the milestone.
2. Show the full list and **wait for my confirmation** before creating anything.
3. On approval, create them with `gh issue create ...`, attach the milestone, and add them
   to the project board.

Do not invent scope beyond the roadmap/sprint file. Keep issues small enough to finish in
one `/work` pass.
