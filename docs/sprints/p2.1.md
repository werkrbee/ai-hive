# P2.1 — the assurance loop

Goal: build the agents' control systems at the same pace as the agents. Every agent the
House ships carries a passport stating what it may and may not do, held by four controls:
a trust evaluation that catches drift, a tamper-evident log of what it did and didn't do,
rollback to an earlier version or state, and a human review queue. Sub-agents and clones
can only narrow their parent's passport. Rationale: `docs/factory-thesis.md` ("Defensive
co-scaling").

Every item is an issue on the `P2.1 — assurance loop` milestone (epic #122). Work them in
the order below with `/work <issue>`.

**Guardrail:** no agent gains autonomy before its controls do. Hosted Barry's deploy
(#120) waits for the passport, the audit log and the review queue. His other
implementation issues (#115–#119) can go ahead alongside this milestone.

## Build

The passport and the audit log come first, because the other controls write to them or
read from them.

- [ ] **Agent passport.** (#125) The schema, passports for Barry and Patricia, a CI check,
      and a link from each Agent Card.
- [ ] **Tamper-evident audit log.** (#126) Append-only and hash-chained, written by the
      workflows-hive engine, with a verifier and the Charter rule against deleting or
      editing it.
- [ ] **Human review queue.** (#129) Approvals, drift and escalations across every run
      and agent, answered through the CLI and MCP.
- [ ] **Trust evaluation and drift.** (#127) A baseline in each passport, re-runs on
      change and on a schedule, and drift sent to the review queue.
- [ ] **Rollback.** (#128) To an earlier passport or checkpoint, with compensating
      actions for effects outside the system.
- [ ] **Sub-agent and clone boundaries.** (#130) Narrowed delegation, explicit context and
      cache scope, with every delegation logged.

Close the epic (#122) when all eight are done.

## Definition of done

- Barry and Patricia each have a passport that CI validates.
- Every step decision, approval, denial and cancel is in an audit log a verifier can
  check, and the Charter forbids deleting or editing it.
- A human sees approvals, drift and escalations in one review queue.
- An agent can be rolled back to an earlier passport, and a run to an earlier checkpoint.
- A delegate can't hold more than its parent, and every delegation is logged.
