# P0 — the runtime layer

Goal: give the House a runtime layer, so products built on it get durable, resumable
execution and replaceable workers on the current MCP spec. lineup proved this is the
missing layer.

Every item is already an issue on the `P0 — runtime layer` milestone. Work them in the
order below with `/work <issue>`.

**Guardrail** (adapted from `ROADMAP.md`): adopt the latest MCP first (A2A follows in
P1), and let `workflows-hive` prove the runtime layer before work spreads to other hives.
A working product on durable execution teaches more than eight hives at spec parity.

## Workflows track

Run these in order. The workflow contract is built on MCP Tasks, so the spec bump comes
first.

- [ ] **MCP spec bump.** (#8) Point every MCP spec reference at the 2026-07-28 spec and
      state in the mcp-hive README which version the registry targets, checked against the
      published spec.
- [ ] **Workflow design note.** (#10) Create `hives/workflows-hive/` (README, standard hive
      layout) and put the design note there: MCP Tasks as the interface, Temporal evaluated
      as the engine, and the persisted plan + checkpoint shape defined.
- [ ] **Resumable workflow spike.** (#11) Inside `hives/workflows-hive/`, one two-step
      workflow that checkpoints, survives a process restart, resumes at step 2, and reports
      result and cost.

Close the `workflows-hive` epic (#12) when #10 and #11 are done.

## Alongside

- [ ] **Execution-contract schema.** (#7) Define a worker by capability, inputs, expected
      output, budget, and permissions, with Barry and Patricia expressed against it. Can
      start any time.
- [ ] **Server Cards discovery.** (#9) mcp-hive reads remote servers' `.well-known` Server
      Cards and `install.py --dry-run` validates them. Starts once #8 lands.

## Definition of done

- MCP references and mcp-hive target the 2026-07-28 spec.
- `hives/workflows-hive/` exists (#10) with a design note and a workflow that resumes
  after a restart (#11).
- Workers are defined by an execution contract, Barry and Patricia included.
- mcp-hive can point at a remote server's Server Card, and `--dry-run` validates it.
