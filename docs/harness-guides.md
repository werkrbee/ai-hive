# The harness guides

_Generated from `harnesses.json` by `python3 scripts/harnesses.py matrix`; edit the registry or the guides, not this file._

One page for picking a harness: for each of the twenty the House aligns with, the guide to using the House in it, its row in the [harness matrix](harness-matrix.md), what it costs and the runs recorded in it. Why these twenty: [`harness-ecosystem.md`](harness-ecosystem.md). A guide explains the surfaces and how to get the most from them; the matrix holds the paths, sources and effective rates, and an unverified row is a lead, not a fact. A price is as of the date beside it, so check it again before a decision rests on it. Where a guide or a run doesn't exist yet, the page says none yet; each harness's alignment issue adds them.
