# AI cost forecast template

Copy this worksheet for each workload and reporting period. Use the same scope, currency, units and outcome definition for the baseline, forecast and actuals. Keep low, base and high scenarios separate.

For each forecast scenario use quantity × unit rate or the documented fixed charge. Reconcile overlapping sources before totaling. Keep unattributed charges visible as `unallocated`. Leave totals incomplete when a required charge is unknown, and describe the missing input. Use the same cost drivers for baseline and actuals, with their own sources and reporting dates.

When actuals are known, calculate forecast variance as actual minus base forecast. Calculate variance percent only for a positive base forecast. Divide total USD by successful outcomes only when the denominator is known and positive. For workflow-level outcomes, count each success once per reporting scope, even when several charge rows support it. Document any approval in the existing budget process.
